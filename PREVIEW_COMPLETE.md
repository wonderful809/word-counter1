   - Entire site switches to dark theme
   - Persists when you navigate between pages
   - Stored in browser localStorage

2. **Keyboard Shortcuts Badge**: Hover over ⌨️ (bottom-left)
   - Popup appears showing all shortcuts
   - Try pressing the shortcuts!

3. **Tool Cards**: Hover over any card
   - Orange preview box slides up from bottom
   - Shows additional description

4. **CTA Button**: Click "Try Word Counter →"
   - Smooth page transition
   - Navigate to Word Counter tool

### On Tool Pages
1. **Type in Textarea**:
   - Watch character count badge update (bottom-right)
   - See animated number counters
   - Notice smooth transitions

2. **Focus Textarea**:
   - Click in textarea
   - See animated orange glow effect

3. **Try Keyboard Shortcuts**:
   - Press `Ctrl+Shift+X` to clear text
   - See toast notification appear

4. **Scroll Down**:
   - Back-to-top button appears after 200px
   - Click it for smooth scroll

5. **Drag & Drop**:
   - Find a .txt file
   - Drag it over textarea
   - See orange dashed border
   - Drop to load content
